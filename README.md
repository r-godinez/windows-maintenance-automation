# 🧰 Windows Maintenance Automation

A collection of PowerShell scripts designed to automate system maintenance, updates, monitoring, and security tasks on Windows systems.

## 📂 Modules

| Category | Description |
|-----------|--------------|
| **update/** | Scripts for updating software via Winget and Windows Update. |
| **security/** | System hardening, event log monitoring, and firewall configuration. |
| **monitoring/** | Performance tracking, health reports, and automated email alerts. |
| **backup/** | Incremental backup scripts with integrity verification. |
| **scheduler/** | Task Scheduler automation for weekly or daily tasks. |
